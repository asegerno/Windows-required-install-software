# Windows-required-install-software

Windows 各世代作業系統裝機必備基礎套件、運行庫與企業防護終端 (Essential Software & Enterprise Endpoint for Windows).

---

## 📌 簡介 (Introduction)
本倉庫收錄 Windows 各系統版本（Windows XP、Vista、現代 Windows 10/11）在初始安裝完成後，所需之核心環境依賴、運行庫元件與官方企業級安全防護軟體。

---

## 📂 系統版本目錄索引 (OS Directories)
* **[For Windows New OS](./For%20Windows%20New%20OS)**：適用於 Windows 10 / Windows 11 的現代裝機必備工具
* **[For Windows Vista](./For%20Windows%20Vista)**：適用於 Windows Vista 的最後相容版本組件
* **[For Windows Xp](./For%20Windows%20Xp)**：適用於 Windows XP SP3 的歷史相容運行庫與工具
